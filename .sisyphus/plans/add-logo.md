## Context

### Original Request
User wants to add an owl logo image to the HTML web report generated by `--web` mode. The logo should appear in the header bar alongside the "Tawny" title.

### Interview Summary
**Key Discussions**:
- **Placement**: Web report only (not TUI mode)
- **File location**: `assets/logo.png`
- **Optimization**: Resize before base64-encoding to keep reports small (~5-10KB vs ~2MB)
- **Self-contained**: Logo must be embedded as base64 data URI since reports are single-file HTML

### Metis Review
**Identified Gaps** (addressed):
- **Image size bloat**: 1024×1024 PNG → ~2.1MB base64. Resolved: resize to 128×128 (retina-ready for 64px display) using macOS `sips` before encoding
- **Path resolution**: `generateHtml()` currently does zero I/O. Resolved: use `import.meta.dir` to resolve path relative to `web.ts`, not `process.cwd()`
- **npm distribution**: `package.json` `files` excludes `assets/`. Resolved: add `"assets"` to the array
- **Graceful degradation**: Logo missing at runtime. Resolved: throw with clear error (dev tool run from source)
- **Function purity**: `generateHtml()` is currently pure. Resolved: read logo at module level as a constant, pass into template
